# Nom du Projet

## Description

Cette application est un système de gestion bancaire permettant aux clients de consulter les services proposés
par la banque et aux employés de gérer les inscriptions et les comptes clients.

## Navigation du projet

L'application démarre sur la page de connexion (*login*). À partir de cette page, l'utilisateur peut cliquer sur **Home**
pour accéder à la présentation des différents services proposés par la banque. En cliquant sur **Sign In**, 
l'utilisateur est redirigé vers les interfaces réservées aux employés de la banque,
dédiées à l'inscription et à la gestion des comptes clients.
Notez que la section **Transactions** ne s'affiche pas actuellement, 
car cette partie du code est développée en PHP et n'est pas encore intégrée dans l'environnement actuel.




## Utilisation

1. Lancer l'application
2. Accéder à la page de connexion (*login*)
3. Cliquer sur **Home** pour voir les services de la banque
4. Cliquer sur **Sign In** pour accéder à l'espace employé (inscription et gestion des comptes clients)

## Remarques

- La partie **Transactions** n'est pas encore fonctionnelle car le code correspondant est écrit en PHP et
- nécessite une configuration serveur supplémentaire.
